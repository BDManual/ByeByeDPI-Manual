# ByeByeDPI Manual

Документация состоит из Markdown-файлов и изображений. После изменений в [репозитории](https://github.com/BDManual/ByeByeDPI-Manual) GitHub Actions собирает их в сайт [byebyedpi.xyz](https://byebyedpi.xyz).

## Подготовка

Для локальной работы понадобятся:

1. [Hugo Extended](https://gohugo.io/installation/)
2. [Git](https://git-scm.com/downloads)
3. [Go](https://go.dev/doc/install) - используется для загрузки темы Hextra

Сделайте [форк репозитория](https://github.com/BDManual/ByeByeDPI-Manual/fork) и клонируйте его, заменив `<ВАШ_ЛОГИН>` на имя пользователя GitHub:

```bash
git clone https://github.com/<ВАШ_ЛОГИН>/ByeByeDPI-Manual.git
cd ByeByeDPI-Manual
```

Для небольшой правки можно обойтись без локального запуска: откройте нужный файл в папке [`content`](content), нажмите **Edit this file** и предложите изменения через Pull Request.

## Работа с Hugo

В директории репозитория выполните:

```bash
hugo server -D
```

При первом запуске Hugo скачает тему Hextra. Когда сайт будет готов, откройте [http://localhost:1313/](http://localhost:1313/). Изменения в файлах будут отображаться автоматически.

Страницы находятся в [`content/docs`](content/docs):

- `.ru.md` - русская версия;
- `.en.md` - английская версия.

При добавлении страницы создавайте оба языковых файла. Используйте структуру существующих страниц и добавляйте в начало:

```yaml
---
title: Название страницы
weight: 9
---
```

`weight` определяет порядок страницы в боковом меню.

## Требования к тексту и изображениям

- Проверяйте орфографию, пунктуацию и работоспособность инструкций.
- По возможности обновляйте русскую и английскую версии одновременно.
- Имена новых изображений должны содержать только строчные латинские буквы, цифры и дефисы: `proxy-settings.png`.
- Помещайте изображения в [`static/images`](static/images) и вставляйте как `![Описание](/images/proxy-settings.png)`.
- Делайте скриншот только нужной части экрана, скрывайте личные данные и сжимайте слишком большие файлы.

## Отправка изменений

Перед отправкой убедитесь, что сайт собирается без ошибок:

```bash
hugo --minify
```

Запушьте изменения в свой форк и нажмите **Create Pull Request** в интерфейсе GitHub. После проверки Pull Request либо будет принят, либо вы получите замечания. Исправления достаточно отправить в ту же ветку — они автоматически появятся в уже созданном Pull Request.

## Важно

> **Вы используете данный материал на свой страх и риск.**

Обход DPI зависит от провайдера, времени и конкретных ресурсов. Материалы предоставлены в образовательных целях. Используйте их в рамках закона и только в сетях, где у вас есть соответствующие права.
